# 100-projects-of-react
# 🎨 Gradient Generator Tool  

This is **Day 1 Project** of my **100 React Projects Challenge**.  
A simple tool that generates **linear and radial gradients**, and lets you copy the color codes with one click.  

---

## 🚀 Features  
- Generate random gradients (linear & radial)  
- Copy HEX / RGB color codes directly to clipboard  
- Smooth UI updates using React hooks  

---

## 🔑 What I Learned  
- **Math.random() + Math.floor()** → Generate random color values  
- **toString(), padStart(), padEnd()** → Convert numbers to proper hex format  
- **RGB → HEX conversion function** → Learned logic building for color formats  
- **linear-gradient & radial-gradient** → Practiced CSS gradients  
- **navigator.clipboard.writeText()** → Copy text programmatically  
- **useState & useEffect** → Manage state and auto-update UI in React  

---

## 💡 Takeaway  
This project helped me improve my **logic building skills** and apply **React hooks** in a practical way instead of just theory.
